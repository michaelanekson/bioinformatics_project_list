# Microarray Transcriptomics Analysis (limma)

This folder contains a complete microarray transcriptomics analysis pipeline
using limma, developed during biomedical research projects on hypertension
and exercise intervention.

## Methods
- Differential expression: limma
- QC: boxplot, PCA
- Functional analysis: GSEA (MSigDB), KEGG, pathview
- Species: Rattus norvegicus

## Structure
- 01–02: Setup & preprocessing
- 03: Differential expression
- 04: QC & visualization
- 05–06: Functional interpretation
