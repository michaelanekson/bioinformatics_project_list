# GWAS Analysis Using PLINK2

## Overview

This folder contains a **reproducible, end-to-end GWAS pipeline implemented with PLINK 2**.  
The pipeline follows **research-grade best practices** commonly used in large-scale human genetics studies and is designed to be:

- Transparent and modular
- Suitable for publication and downstream meta-analysis
- Compatible with tools such as **METAL**, **FUMA**, and **PRS pipelines**

Only code is included. No raw or sensitive data are stored in this repository.
